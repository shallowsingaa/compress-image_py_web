# 更新日志

本文档记录 `compress-img-cli` npm 包的用户可见变化。

## 1.0.0 - 2026-05-16

- 首次 npm 分发版本。
- 包名为 `compress-img-cli`。
- 安装后的全局命令为 `compress-img`。
- 支持 Windows 和 Linux。
- Windows 包含 `resources/win/compress-image.exe`。
- Linux 包含 `resources/linux/compress-image`。
- Windows 支持 `--clipboard` 剪贴板模式。
- Linux 文件压缩可用，剪贴板模式会给出友好提示。
