# 安全说明

## 支持版本

当前维护最新发布版本。

## 报告安全问题

请不要把安全问题直接公开到普通 issue 中。优先通过项目维护者的私有渠道报告，并提供：

- 受影响版本
- 复现步骤
- 影响范围
- 是否涉及恶意图片、路径写入、命令执行或敏感文件读取

## 安全边界

- `compress-img-cli` 会读取用户指定的本地图片路径。
- Windows `--clipboard` 模式会读取当前剪贴板中的图片或文件列表。
- 压缩逻辑依赖 Pillow 解析图片；请避免处理来源不可信的大批量异常图片。
- npm 发布使用的 access token 不应写入仓库、文档样例以外的配置文件或提交记录。
